RETROWAVE CAMERA — PWA protótipo

ARQUIVOS
- index.html: interface, filtros e exportação
- manifest.json: nome, ícones e modo de abertura
- sw.js: cache offline básico
- icons/: ícones da aplicação

HOSPEDAGEM
1. Envie todos os arquivos e a pasta icons para um repositório público no GitHub.
2. Em Settings > Pages, escolha Deploy from a branch, selecione main e /(root), e salve.
3. Aguarde o endereço HTTPS do GitHub Pages ficar disponível.
4. Abra o endereço no Safari do iPhone > Compartilhar > Adicionar à Tela de Início.
5. Abra pelo novo ícone. Se atualizar o código, pode ser necessário fechar e abrir o app para atualizar o cache.

LIMITAÇÕES
- É uma PWA, não um app nativo de App Store.
- O filtro é básico e não reproduz o algoritmo proprietário do Dazz Cam.
- A captura nativa ao vivo e efeitos 3D ainda não estão implementados.
- Para funcionar offline, a primeira abertura deve ocorrer com internet.
